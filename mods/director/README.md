# «Режиссёр» — мод для съёмки сериала в GTA San Andreas (Android)

CLEO-скрипт для съёмки машинимы. На экране появляется меню с кнопками
по краям. В нём ты настраиваешь камеру, кадры, актёров и погоду, а потом
нажимаешь **«МОТОР!»**: меню исчезает, и проигрывается вся сцена из
отснятых кадров (плавные пролёты камеры и монтажные склейки).

Рассчитан на **GTA SA Android 2.00** + **CLEO Mod для AML 2.0.1.5** (или
новее).

## Файлы

| Файл | Что это |
|------|---------|
| `build/director_ru.csi` | русские надписи, запуск из CLEO-меню |
| `build/director.csi` | английские надписи, запуск из CLEO-меню |
| `build/*.csa` | то же, но грузится всегда, включается удержанием верха экрана по центру 2 секунды |

Ставь **один** файл. Сначала попробуй `director_ru.csi`. Если вместо
русских букв видны непонятные символы, значит шрифт твоей сборки не
понимает такую кодировку. Тогда ставь `director.csi` с английскими
надписями.

## Как устроен экран

CLEO делит экран на 9 зон, и у каждой зоны есть своя кнопка у края экрана:

```
 [1]        [4]        [7]
 [2]     (картинка)    [8]
 [3]        [6]        [9]
```

Центр экрана свободен под кадр. Нажатие срабатывает, когда отпускаешь
палец; нажатая кнопка подсвечивается оранжевым. Верхняя кнопка [4] в
подменю всегда **НАЗАД**.

## Меню

**Главное меню**

| Кнопка | Действие |
|--------|----------|
| КАМЕРА | полёт камеры |
| КАДРЫ | список кадров сцены |
| АКТЁРЫ | актёры и анимации |
| МИР | время, погода, слоу-мо, полосы |
| МОТОР! | проиграть сцену. Касание экрана останавливает |
| + КАДР | быстро добавить кадр из текущей камеры |
| СКРЫТЬ МЕНЮ | убрать кнопки, чтобы посмотреть кадр. Касание возвращает |
| ВЫХОД | выключить мод (нажать два раза) |

**Камера.** Кнопки полупрозрачные, удерживай их: ВПЕРЁД, НАЗАД, ВЛЕВО,
ВПРАВО, ВВЕРХ, ВНИЗ, НАКЛОН ВВЕРХ, НАКЛОН ВНИЗ. Чем дольше держишь, тем
быстрее камера. **МЕНЮ** в центре возвращает в главное меню.

**Кадры**

| Кнопка | Действие |
|--------|----------|
| + КАДР | добавить кадр: камера **плавно прилетит** к нему из предыдущего |
| + СКЛЕЙКА | добавить кадр с **монтажной склейкой** (мгновенная смена ракурса) |
| УДАЛИТЬ | удалить выбранный кадр |
| ПРЕДЫДУЩИЙ / СЛЕДУЮЩИЙ | выбрать кадр, камера встанет на него |
| КАМЕРА | полетать, чтобы найти следующий ракурс |
| ЕЩЁ | вторая страница |

Вторая страница: ВРЕМЯ + / ВРЕМЯ − (длительность кадра, шаг 0,5 сек),
ПЛАВНО / СКЛЕЙКА (сменить тип перехода), ЗУМ + / ЗУМ − (удерживай),
ПЕРЕСНЯТЬ (заменить выбранный кадр текущей камерой), УДАЛИТЬ ВСЁ
(нажать два раза).

Вверху показано: «КАДР 2 ИЗ 5», тип перехода и длительность. Можно
сделать до 24 кадров.

**Как проигрывается сцена.** Каждый кадр длится своё время. Если
следующий кадр «плавный», камера летит к нему всё это время. Если
«склейка», камера стоит на месте, а потом мгновенно переключается.

**Актёры**

| Кнопка | Действие |
|--------|----------|
| + АКТЁР | создать актёра в 6 м перед камерой, лицом к камере (до 6 актёров) |
| МОДЕЛЬ | кого создавать: случайный, Грув, Баллас, Вагос, полиция, спецназ, ФБР, армия, медик |
| ВЫБРАТЬ | кем управлять: CJ, актёр 1, 2… |
| УДАЛИТЬ | удалить выбранного актёра |
| АНИМАЦИЯ + / − | следующая или предыдущая анимация для выбранного |
| ЕЩЁ | ИДТИ СЮДА, БЕЖАТЬ СЮДА (в точку перед камерой), СТОП, ДРУГ НА ДРУГА (для диалога), В КАМЕРУ (повернуться к камере) |

Анимации: разговор, телефон, устал, руки вверх, испуг, неприличный жест,
падает, бандитский разговор 1 и 2, рукопожатие, «да», «нет», кричит,
показывает вверх, машет, танец. Имя текущей анимации видно вверху.

**Мир:** ЧАС + / ЧАС −, ПОГОДА, ЗАМЕДЛЕНИЕ (100% → 50% → 25%), ПОЛОСЫ
(кино-полосы), ПУСТЫЕ УЛИЦЫ (без прохожих и машин), СКРЫТЬ CJ. Кнопки
показывают, что сейчас включено.

**Скрыть CJ** нужно, когда CJ не участвует в сцене. Он становится
невидимым «оператором» и летит вместе с камерой, чтобы город прогружался
вокруг кадра. Когда CJ снова показываешь, он встаёт на землю под камерой.
Пока CJ виден, не улетай камерой дальше примерно 150 м от него.

## Как снять сцену

1. **МИР:** выставь время и погоду, включи полосы.
2. **АКТЁРЫ:** создай актёров, расставь их (ИДТИ СЮДА), поверни друг к
   другу, включи анимации.
3. **КАДРЫ → КАМЕРА:** найди первый ракурс, нажми МЕНЮ → **+ КАДР**.
4. Снова КАМЕРА → следующий ракурс → **+ КАДР** (пролёт) или
   **+ СКЛЕЙКА** (смена плана). Повтори для всех кадров.
5. В КАДРЫ → ЕЩЁ подправь длительность кадров.
6. Включи запись экрана на телефоне и нажми **МОТОР!**. Меню исчезает
   на всё время сцены, в конце возвращается. Начало и конец записи
   обрежь при монтаже.

## Важно

- Кадры хранятся, пока мод включён. После выхода из мода список
  очищается.
- Пока мод включён, CJ неуязвим и прохожие его не замечают. При выходе
  всё возвращается как было.
- Мод проверен на эмуляторе скрипта, но не на реальном телефоне. Если
  кнопки съехали, что-то не работает или игра вылетела, пришли скриншот
  или crashlog.

## Сборка из исходника

Исходник скрипта генерирует `gen_director.py`. Готовые `director.txt`
и `director_ru.txt` лежат рядом, их руками не правят.

```
python3 mods/director/gen_director.py en > mods/director/director.txt
python3 mods/director/gen_director.py ru > mods/director/director_ru.txt
python3 tools/scm_asm.py mods/director/director_ru.txt mods/director/build/director_ru.csi
python3 tools/scm_asm.py mods/director/director_ru.txt mods/director/build/director_ru.csa -D CSA
```

`tools/scm_asm.py` — небольшой ассемблер CLEO-скриптов. Опкоды взяты из
базы Sanny Builder для SA Mobile и сверены с исходниками CLEO Mod.
