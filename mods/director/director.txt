// =====================================================================
//  REZHISSYOR (Director Mode) for GTA San Andreas Android 2.00 (CLEO)
//  Machinima tool: free camera, camera moves A->B, actors, animations,
//  time / weather / slow motion, widescreen, empty streets.
//
//  Build:  python3 tools/scm_asm.py mods/director/director.txt director.csi
//          python3 tools/scm_asm.py mods/director/director.txt director.csa -D CSA
//
//  Screen is split by CLEO into 9 touch zones:
//      1 4 7
//      2 5 8
//      3 6 9
//  Zone 5 (centre): tap = next mode, hold 1.5 s = exit.
//
//  Local variables:
//   0@  player char             1@  mode 0..3
//   2@ 3@ 4@  camera x y z      5@  heading (deg)   6@  pitch (deg)
//   7@  field of view
//   8@ 9@ 10@ 11@  temp floats  12@ temp int / selected char handle
//   13@..17@  shot point A (x y z heading pitch)
//   18@..22@  shot point B (x y z heading pitch)
//   23@ shot duration (ms)      24@ actor 1 (-1 = none)
//   25@ animation index         26@ weather id
//   27@ time scale index        28@ flags: 1 widescreen, 2 empty streets, 4 CJ hidden
//   29@ actor 2 (-1 = none)     30@ selected: 0 CJ, 1 actor 1, 2 actor 2
//   31@ temp                    32@ timer: overlay / hold   33@ timer: acceleration
// =====================================================================
