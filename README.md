# GTASA-Mod-Manager

Android-приложение для установки модов в GTA San Andreas (Android 2.00).

## Возможности

- **Любые файлы игры.** Заменяются и добавляются файлы любого формата: текстуры (`texdb`),
  модели, `data`, скрипты, **звук** (`audio/SFX`, `audio/STREAMS`, радио — `.osw`, `.wav`,
  `.mp3`, `.ogg` и что угодно ещё), **катсцены** (`anim/cuts.img` и их звук) и т.д.
  Фильтра по расширениям нет.
- **Моды больше 5 ГБ.** Архив читается потоком, файл за файлом: ничего не грузится в память
  и не распаковывается во временную папку. Поддерживается ZIP64 (файлы и архивы больше 4 ГБ).
  Можно ставить и уже распакованный мод из папки.
- **Совмещение модов.** Моды ставятся поверх друг друга. Каждый мод можно удалить в любом
  порядке: если тот же файл потом заменил другой мод, файл останется от него, а остальные
  вернутся к состоянию до удалённого мода. Есть кнопка «Удалить все моды (вернуть оригинал)».
- **Откат.** Перед заменой файл копируется в
  `Android/data/com.gtasa.modmanager/files/backups`. Если установка прервалась с ошибкой,
  уже заменённые файлы возвращаются автоматически.

## Куда кладутся файлы

Для каждого файла из мода:

1. Ищется файл с тем же относительным путём (лишние верхние папки в архиве, например
   `files/` или `com.rockstargames.gtasa/files/`, отбрасываются).
2. Иначе — файл с тем же именем, если он в игре один (или один в папке с тем же именем).
3. Иначе файл считается новым и создаётся, если в его пути есть папка, которая уже есть
   в корне игры (`audio/...`, `texdb/...`, `data/...`).
4. Остальное (readme и т.п.) пропускается — список показывается после установки.

## Ограничения

- Поддерживается ZIP (deflate/stored). Deflate64, 7z, RAR — распакуйте и выберите
  «Установить мод из папки».
- Для бэкапов нужно свободное место примерно равное размеру заменяемых файлов.
- Бэкапы удаляются вместе с приложением — сначала удалите моды.
- На Android 11+ системный выбор папки может не пускать в `Android/data`.
- Тестируйте сначала на копии игры.
