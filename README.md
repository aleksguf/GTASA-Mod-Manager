# GTASA-Mod-Manager
Android-приложение для установки модов в GTA San Andreas (Android 2.00).

## Моды

- [«Режиссёр»](mods/director/README.md): CLEO-мод для съёмки машинимы и
  сериалов внутри игры (свободная камера, пролёты камеры A → B, актёры
  с анимациями, время, погода, слоу-мо, кинополосы). Готовые файлы лежат
  в `mods/director/build/`.
